# Stage 02: Tooling Setup Project Scaffold

This repository establishes a reproducible Python data engineering project template for Stage 02. The primary goal is to standardize environment configuration, manage project secrets safely via environment variables (`.env`), enforce a clean modular project structure, and ensure seamless deployment through Jupyter notebooks and Git version control.

## Directory Layout
- `data/`: Storage for raw and processed datasets.
- `notebooks/`: Jupyter notebooks for setup verification and analysis.
- `src/`: Reusable Python modules and configuration code.
- `.env.example`: Template file for required environment variables.
