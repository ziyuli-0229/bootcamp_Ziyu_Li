# Reports & Deliverables Documentation

## Audience & Format Choice
- **Target Audience**: Executive Leadership, Business Stakeholders, and Portfolio Managers.
- **Chosen Format**: Standalone Markdown Report (`final_report.md`) with self-contained high-resolution charts.
- **Rationale**: Executives require decision-oriented summary bullets, explicit sensitivity tables, and clear "What this means for you" sections without navigating raw code or complex notebook dependencies.

## Asset Structure
- `final_report.md`: Core stakeholder deliverable containing executive summary, charts, sensitivity tables, and decision recommendations.
- `images/`: High-DPI exported visuals referenced within the primary report:
  - `risk_return.png`: Scatter plot comparing risk-return profiles across scenarios.
  - `return_by_scenario.png`: Bar chart highlighting return yield variations.
  - `metricA_over_time.png`: Line chart tracking performance trajectories across categories.
